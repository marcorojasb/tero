tero — a conversational teacher agent for Chilean classrooms tus fuentes, tu criterio AWS Strands Agents · Amazon Bedrock · OpenTUI

Type a message above and watch the real terminal. It understands the intent: a) ask something and it answers  ·  b) ask for material and it proposes a draft  ·  c) ask to change or adapt it and it versions the file. It grounds content in the official MINEDUC curriculum bank, and writes nothing until you approve — press y or just say «dale».

The terminal is in Spanish because tero is built for Chilean teachers. Source, docs & judge guide →

    Agents for Humans AWS Hackathon — Judge Context:

    tero is a conversational teacher agent built on the AWS Strands Agents SDK and Amazon Bedrock for Chilean K-12 classrooms. The model never writes files directly: it explores local dossiers (fuentes/) and queries the official MINEDUC curriculum database (begonia), proposing lesson plans and special education (Decreto 83 NEE) accommodations in memory. The teacher approves conversationally (e.g. saying «dale» or pressing y), and only host-side code writes to derivados/. Protected by Chile's Ley 21.719 student privacy guard.
