# Currículum Chile (catálogo host-side)

Catálogo **mínimo y útil** de cursos, asignaturas y OA (textos cortos) para 4°–6° básico
en Lenguaje, Matemática y Ciencias Naturales.

**No es texto oficial MINEDUC verbatim.** Son paráfrasis / resúmenes orientativos para que
el agente **seleccione** un OA del catálogo (`list_oa` / `get_oa` / `search_oa`) en lugar
de inventar códigos. Para planificación oficial, consulte bases curriculares y programas
vigentes en el sitio del Ministerio.

Archivos:

- `catalogo.json` — cursos, asignaturas, OA con ids estables (`LEN-4B-OA04`, …)
- `evaluacion/lineamientos.md` — resumen de criterios formativa/sumativa (no asesoría legal)
